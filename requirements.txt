# 说明：

#   * 国内下载 torch 那个 2.67 GB 轮子很慢，可以先手动下好再用本地文件装：
#       https://download.pytorch.org/whl/cu128/torch-2.9.1%2Bcu128-cp311-cp311-win_amd64.whl
#       https://download.pytorch.org/whl/cu128/torchaudio-2.9.1%2Bcu128-cp311-cp311-win_amd64.whl
#       python -m pip install --no-index --find-links <轮子目录> "torch==2.9.1+cu128" "torchaudio==2.9.1+cu128"
#     然后注释掉下面两行 torch，再跑本文件。
#   * 只唱歌、说话走云端（say.engine = "breeze"）的话，可以删掉 triton-windows / qwen-tts / transformers。
#
